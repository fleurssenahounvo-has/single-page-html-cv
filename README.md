# CV HTML sur une seule page

Projet réalisé dans le cadre du parcours **Single-Page HTML CV** de Roadmap.sh.

## Contenu
- `index.html` : CV structuré avec les éléments sémantiques HTML.
- Aucun framework ni fichier CSS/JavaScript externe n'est nécessaire.

## Exécuter le projet
1. Téléchargez ou clonez le dépôt.
2. Ouvrez le dossier du projet.
3. Ouvrez `index.html` dans un navigateur web.

## Personnalisation avant publication
Remplacez les informations indiquées  :
- nom complet ;
- ville et pays ;
- téléphone et adresse e-mail ;
- établissement et dates de formation ;
- niveaux de langue ;
- liens GitHub et LinkedIn ;
- lien du dépôt du projet.
